# 心理年龄测试 · 你的心理年龄到底多少岁

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像 + 心理年龄（约 12–65）+ 六档锐评 + 日历年龄感对照。

## 在线地址

https://zengpenghui420-glitch.github.io/mental-age/

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我） |
| 维度 | 玩心与游戏感 / 责任与节律 / 情绪节拍 / 好奇开放 / 人际分寸 / 节奏耐心 |
| 结果 | 心理年龄 + 档位 + 主导维度 + 六维雷达 + 特征表现 + 相处/自处建议 + 日历年龄感对照 |
| 解锁 | 小红书订单号。只接受 `P` + 18 位；重复块、逐位 ±1、19 位提示「订单号格式不对」，不会开始。格式通过后立即开始 |
| 提示 | 第一次开始：「验证成功，还可以测 2 次」。重新测试改为「还可以测 1 次」，再改为「这是最后一次」。刷新、继续这一次、恢复结果、查看上次结果不改变这条提示 |
| 三次之后 | 同一订单号仍可进入，提示「验证成功」 |
| 订单请求 | 不请求 `*.vercel.app`，也不读写 Mantle 的 `orders/` |
| 查看上次 | 仅读本机缓存，不改变订单号那条提示 |
| 已发出的码 | 仍走本页原来的 vault 主机 `POST /redeem`、`GET /get`，剩余次数是真实计数。页面不提示旧码 |

## 免责声明

本测试为娱乐向自我观察，非正式心理测量，不能替代专业心理评估或临床诊断。「心理年龄」只是对你近期心态与处事节奏的趣味画像，不是成熟度判决，也不代表你该变成谁；结果会受当下情绪与作答状态影响。
